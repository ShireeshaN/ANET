Extend capability
The retrofit idea

Existing BMS stays at the core. IoT becomes the extension layer.

The page now explains the concept exactly this way: first understand the installed BMS, then add only the IoT components needed to improve visibility, data access and remote insight.

What we retain

Where the current system is healthy and accessible, there is no need to replace it just to add IoT capability.

Existing BMS controllersRetained where interfaces, licences and condition support integration.
Existing field pointsReuse available HVAC, lighting, energy, water and other connected data.
Existing schedules & logicPreserve proven routines instead of rebuilding them without reason.
Existing operator workflowsKeep familiar operations where they remain useful to the facility team.

What IoT adds

The IoT layer extends the installed BMS beyond the limits of its current interface and data coverage.

Gateway connectivityBridge supported BMS protocols and accessible data points.
Additional sensingAdd agreed wireless or wired sensors where the BMS has limited data.
Remote dashboardsExtend approved visibility beyond the local BMS workstation.
Alerts, trends & portfolio viewBring selected conditions, history and multi-site insight into one layer.

Phased rollout

Upgrade the existing building without turning operations upside down.

The phased sequence makes the retrofit message much stronger and more realistic for brownfield / existing-building clients.

Phase 01

Assess

Document the current BMS, protocols, controllers, available points, licences and network conditions.

Phase 02

Integrate

Add the gateway layer and validate the first set of accessible data without disrupting normal BMS operation.

Phase 03

Extend

Add sensors, data normalization, alerts and dashboards where the existing BMS needs more capability.

Phase 04

Scale

Expand the model across more systems, floors, buildings or sites after the initial integration is validated.
